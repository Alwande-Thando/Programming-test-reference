PROGRAMMING TEST REFERENCE

Use this folder as an OPEN-BOOK reference for the programming test.
Adapt examples to the exact question, class names, variables and output required.

FOLDERS
ARRAYS       - 1D/2D arrays, searching, totals, min/max, sorting, parallel arrays
INHERITANCE  - inheritance, overriding, polymorphism, interface + abstract class
EXCEPTIONS   - try/catch/finally, multiple exceptions, throw
QUICK REFERENCE - compact Java syntax and test reminders

TEST WORKFLOW
1. Read the entire question.
2. Identify the required classes, methods and relationships.
3. Find the closest example.
4. Adapt it to the question.
5. Compile.
6. Run the program and check the output.
7. Check spelling/capitalisation of class and method names.

IMPORTANT:
- Follow the exact names/signatures supplied in the test.
- If an interface is provided, implement every required method.
- If a class is abstract, you cannot instantiate it directly.
- Use super(...) when a subclass must call the superclass constructor.
